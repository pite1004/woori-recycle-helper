# 우리동네 분리배출 도우미

버릴 물건을 사진으로 찍으면 내가 사는 구의 배출 방법을 비용 순으로 비교해 주는 모바일 웹앱입니다. 인공지능창의설계 개인 프로젝트(12263359 박상혁) 최종 제출용입니다.

**배포 URL**: https://woori-recycle-helper.vercel.app

**코드 저장소**: https://github.com/pite1004/woori-recycle-helper

`main` 브랜치에 push하면 Vercel이 자동으로 다시 배포합니다.

## 실행 환경

- Node.js 22 이상 (개발에 사용한 버전: 26.13)
- 실제 AI 모드에는 Anthropic API 키가 필요합니다.

## 설치와 실행

1. 의존성을 설치합니다.

   ```bash
   npm install
   ```

2. `.env.example`을 복사해 `.env.local`을 만들고 값을 채웁니다.

3. 개발 서버를 실행하고 http://localhost:3000 을 엽니다.

   ```bash
   npm run dev
   ```

테스트는 다음 명령으로 실행합니다.

```bash
npm test
```

## 환경변수

| 이름 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키. 서버에서만 씁니다. |
| `AI_MODEL` | 사용할 모델. 기본값 `claude-haiku-5-5` |
| `AI_MODE` | `mock`이면 실제 API를 부르지 않고 정해진 결과를 돌려줍니다. 시연과 배포에서는 `live`로 둡니다. |

## 핵심 기능 확인용 입력 예시

1. 처음 화면에서 **인천 미추홀구**를 고릅니다.
2. **사진 찍기**를 누르고 안내에 따라 전기포트를 2~3장 찍습니다(전체 모습, 바닥의 표시나 라벨). 앨범에서 여러 장을 한 번에 골라도 됩니다. 후보에서 전기포트를 고르고 개수 질문에 답합니다.
3. 안내 화면에서 방법을 고르고 **내 기록에 저장**을 누른 뒤, 내 기록에서 다시 엽니다. 저장할 때와 같은 안내가 열립니다.
4. **품목 직접 검색**에서 프라이팬을 고르고 손잡이 질문의 직접 입력 칸에 아래 문장을 넣습니다.
   - `나사가 있는데 잘 모르겠어요` → 확정되지 않고 선택지 버튼으로 다시 묻습니다.
   - `손잡이가 그냥 쭉 붙어 있어요` → "손잡이: 분리 안 됨으로 이해했어요"가 나오고, [맞아요]를 눌러야 다음 질문으로 넘어갑니다.

비용 비교는 프라이팬에서 손잡이 `분리됨`, 재질 `스테인리스·철`을 고르면 잘 보입니다(무료 재활용, 750원 종량제 봉투).

## 구현 범위

- 시범 지역 2곳(인천 미추홀구, 연수구), 품목 29개
- 촬영 가이드에 따라 같은 물건을 2~3장 찍어 한 번에 인식
- 사진 품목 후보, 자유 답변 해석(세 조건을 모두 만족해야 확정)
- 품목 검색, 상태 질문, 비용 비교, 저장과 다시 보기
- 홈 화면에 추가해 전체 화면으로 여는 PWA(오프라인 미지원)

## 제외 범위

전국 지역 규칙, 규칙 자동 수집, GPS 지역 자동 설정, 대형폐기물 신고·결제 대행, 로그인·기기 간 동기화, 배출일 알림
