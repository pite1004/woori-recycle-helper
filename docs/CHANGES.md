# 설계와 구현의 차이

| 구분 | 처음 정한 방식 | 실제로 구현한 방식 | 변경 이유와 영향 |
|---|---|---|---|
| 데이터 | '내 기록' 항목에 고른 방법이 없음 | `SavedRecord`에 `chosenRuleId` 추가 | 설계서 ④ 화면에 "방법 고른 뒤 저장"이 있어서 고른 방법을 함께 저장해야 다시 열 때 똑같이 보인다. |
| 데이터 | 전기포트 질문: 없음 또는 "한 변 1m 미만인가요?" | "함께 버릴 소형가전이 5개 이상인가요?" | 미추홀구·연수구 공식 안내에서 소형가전의 방법을 가르는 기준은 크기가 아니라 개수(5개 이상이면 무상 방문수거)였다. 답에 따라 안내가 실제로 달라진다. |
| 데이터 | `Question`은 id·text·options | `shortLabel` 필드 추가 | "손잡이: 분리 안 됨으로 이해했어요"처럼 해석 확인 문구에 질문의 짧은 이름이 필요하다. |
| 데이터 | 답이 `unknown`이면 `when: {}` 규칙만 남음 | 매칭 로직은 그대로 두고, 의자·매트리스에는 `when: {kind: "unknown"}` 규칙을 데이터로 추가 | 규격에 따라 금액이 달라 `{}` 규칙을 두면 답을 알아도 "금액 확인 필요"가 함께 나온다. 모름일 때만 금액 범위를 보여 주려고 데이터에 넣었다. |
| 데이터 | 확인일 예시 2026-11-07 | `checkedAt`은 실제 확인한 2026-11-06 | 실제로 공식 페이지를 확인한 날짜를 적었다. |
| 기능 | `/api/interpret` 입력은 질문 텍스트·선택지·답변 | 클라이언트는 `itemId`, `questionId`, 답변만 보내고 서버가 사전에서 질문·선택지를 찾음 | AI가 받는 입력은 같다. 클라이언트가 임의의 질문을 넣어 API를 쓰는 일을 막는다. |
| 기능 | 흐름 상태 저장 방식 지정 없음 | ③→④ 상태는 주소(쿼리)에 담음 | 새로고침해도 안내가 유지되고, localStorage에는 지시서가 정한 두 키만 남는다. |
| 화면·기능 | 사진 1장을 찍으면 바로 인식 | 촬영 가이드(① 전체 모습 ② 재질 표시·라벨 ③ 헷갈리는 부분)를 보여 주고 같은 물건을 **2~3장** 찍은 뒤 한 번에 인식. 앨범에서도 여러 장 선택 가능 | 사용자 시험에서 냄비가 프라이팬으로 인식됐다. 한 장으로는 재질·손잡이처럼 애매한 부분을 놓치기 쉬워 여러 각도 사진을 받는다. 촬영 단계가 늘고 AI 요청의 이미지 입력이 최대 3배가 된다. 다만 사전에 없는 물건은 사진을 늘려도 맞게 인식되지 않는다. |
| 기능 | 인식 프롬프트: "가장 비슷한 품목"을 고름 | "종류가 같은 품목만" 고르고, 같은 종류가 없으면 빈 배열 | 사전에 없는 냄비를 모양이 비슷한 프라이팬으로 고른 원인이었다. 이제 사전에 없는 물건은 "직접 골라 주세요" 경로로 간다. |
| 데이터 | 품목 15개 내외 | 29개(냄비, 페트병, 플라스틱 용기, 음료 캔, 부탄가스, 우유팩, 택배 상자, 비닐봉지, 헌옷, 선풍기, 전기밥솥, 거울, 자전거, 소파 추가) | 사용자 시험에서 자주 버리는 물건이 사전에 없어 오인식이 생겼다. 모두 구청 공식 페이지에서 확인한 값만 넣었다. |
| 데이터 | 냄비 질문 없음(신규) | 손잡이 선택지를 3개(전부 금속 / 분리됨 / 분리 안 됨)로 둠 | 냄비는 손잡이까지 금속인 경우가 많아, 프라이팬의 2지선다로는 고철 재활용 대상을 놓친다. |
| 화면 | 품목 검색은 글자를 칠 때마다 결과가 바뀜 | 입력 칸 오른쪽 [검색] 버튼(키보드 검색 키도 가능)을 눌러야 결과와 "‘검색어’ 검색 결과 N개"가 표시됨 | 사용자 의견: 검색이 됐는지 안 됐는지 알기 어려웠다. 결과 개수를 함께 보여 줘 0개일 때도 검색이 실행됐음을 알 수 있다. |
| 화면·기능 | (위 2차 변경) 사진 2~3장 필수 | **1장으로 바로 인식**하고, AI가 "불확실"이라고 답하거나 후보를 못 찾을 때만 "한 장 더 찍으면 더 정확해요" 화면에서 추가 촬영을 권함(최대 3장, [지금 후보로 계속] 가능). 인식 응답에 `certainty`(확실/불확실) 추가 | 사용자 의견: 여러 장을 의무로 하면 정확도는 오르지만 귀찮아서 안 찍을 수 있다. 재질·손잡이는 상태 질문이 이미 확인하므로 사진은 물건 종류만 맞히면 된다. 대부분은 1장으로 끝나고 헷갈리는 물건만 추가로 찍는다. |
| 화면 | 촬영 가이드 2번 "재질 표시·라벨" | 추가 촬영 안내를 "바닥이나 뒷면": 표시나 라벨이 없으면 그대로 찍으면 된다고 안내 | 사용자 의견: 오래된 물건은 라벨이 뜯기거나 없을 수 있다. |
| 화면 | 설정 탭(지역 변경) | 별도 경로 없이 `/setup?change=1` 재사용 | 설계서의 화면 5개를 그대로 유지한다. |
