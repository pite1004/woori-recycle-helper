# 개인정보와 보안

## 수집·저장하는 정보

| 정보 | 저장 위치 | 기간 |
|---|---|---|
| 지역 코드 | 브라우저 localStorage `settings` | 사용자가 지울 때까지 |
| 품목, 답변, 확정 방식, 고른 방법, 저장 일시 | 브라우저 localStorage `records` | 사용자가 지울 때까지 |
| 사진 | 저장하지 않음. 줄인 JPEG를 AI 요청에만 쓰고 버림 | 요청이 끝나면 앱에 남지 않음 |
| 직접 입력한 답변 원문 | 저장하지 않음. AI 해석에만 씀 | 요청이 끝나면 앱에 남지 않음 |

로그인과 서버 DB가 없어 기록은 기기 밖으로 나가지 않는다. 답변은 선택지 id로만 저장한다.

## 위험과 대응

| 위험 | 대응 |
|---|---|
| 사진에 집 내부나 개인정보가 찍힘 | 앱과 서버에 보관하지 않고, 서버 로그에는 오류 종류만 남긴다. 다만 사진은 분석을 위해 Anthropic API로 전송된다. |
| API 키 유출 | AI 호출은 서버 Route Handler에서만 한다. 키는 환경변수로만 다룬다. |
| 공개 URL로 API를 과도하게 호출 | 이미지 2MB, 텍스트 200자 제한을 둔다. 요청 횟수 제한은 구현하지 않았으므로 Anthropic 콘솔의 사용 한도를 낮게 설정한다. |
| 답변 입력으로 AI 지시를 바꾸려는 시도 | 질문과 선택지는 서버 사전에서 찾고, 결과는 선택지 id 검증과 사용자 확인을 거친다. |
| 공용 기기에 기록이 남음 | 기록이 이 기기 브라우저에만 저장된다고 화면에 안내한다. 앱 안의 기록 삭제 기능은 지시서 범위에 없어 구현하지 않았다. |

## 키 점검 결과

2026-11-06, `node_modules`와 `.next`를 뺀 프로젝트 전체를 `grep`으로 검색했다. 저장소가 아직 Git이 아니어서 `git grep` 대신 썼다.

- 키 형식(`sk-ant-` 뒤에 8자 이상): 일치 없음
- `sk-ant` 문자열: 점검 명령을 설명한 `CLAUDE.md`와 이 문서에서만 일치. 실제 키가 아니다.

커밋 전에 `git grep -i "sk-ant"`로 다시 확인한다.

`.env*`는 `.gitignore`에 있고 `.env.example`만 커밋 대상이다.
