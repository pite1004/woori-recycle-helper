# 확인이 필요한 규칙 값

공식 페이지에서 찾지 못한 값이다. 앱에는 "확인 필요"(금액은 `null`)로 들어 있다. 확인하면 `data/rules.json`을 고치고 `checkedAt`을 바꾼다.

## 먼저 확인할 것 (시연에 영향)

| 값 | 규칙 | 확인할 곳 |
|---|---|---|
| 소형 폐가전 수거함 이용 요일·시간 | `mh-electric-kettle-box`, `mh-hair-dryer-box`, `ys-…-box` | 미추홀구 1844-1652, 연수구 032-749-7872 |
| 연수구 대형폐기물 배출 요일 | `ys-chair-*`, `ys-mattress-*`, `ys-umbrella-sticker` | 연수구 032-749-7873, '우리동네 배출요일' 메뉴 |
| 미추홀구 전자레인지 1개 방문수거 가능 여부 | `mh-microwave-visit` (주의사항으로 안내 중) | 1599-0903 또는 15990903.or.kr |

| 값 | 규칙 | 확인할 곳 |
|---|---|---|
| 연수구 PP마대 요일·시간·장소, 수거 요청처 | `ys-broken-glass-pp`, `ys-broken-ceramic-pp` | 연수구 '동별 수집·운반업체' 메뉴 |
| 연수구 유리병 배출 봉투 | `ys-glass-bottle-recycle` | 연수구 재활용 담당 032-749-7872 |
| 폐건전지·폐형광등·의류 수거함 이용 요일·시간 | `*-battery-box`, `*-fluorescent-lamp-box`, `mh-blanket-clothes-box` | 행정복지센터 |
| 연수구 이불 배출 방법 (현재 규칙 없음) | 없음 | 연수구 032-749-7852 |

| 코팅 프라이팬의 구별 재활용 여부 | `*-frying-pan-bag` | 각 구 청소 부서 |
| 연수구 의자 '그 밖의 의자' 금액 | `ys-chair-sticker-other` | 연수구 수수료 안내 |

## 다시 살펴볼 값

| 내용 | 이유 |
|---|---|
| 미추홀구 대형폐기물 수수료 | 수수료표 작성일이 2019.01.29다. 의자 4,000원은 현재 안내 페이지 예시와 일치하지만 다른 금액은 최신인지 확인하지 못했다. |
| 연수구 대형폐기물 수수료 | 페이지에 시행일이 없다. 2024년 6월 1일부터 상시 10% 할인 안내가 있어 실제 결제액이 다를 수 있다. |
| 연수구 깨진 유리·도자기 | 재활용 페이지는 종량제 또는 황색봉투, 생활폐기물 페이지는 불연성 PP마대로 안내한다. 앱에는 종량제와 PP마대를 넣었다. |
| 미추홀구 매트리스 규격 | 수수료표는 1인용·2인용만 구분한다. 더블·퀸·킹·라지킹을 2인용(9,000원)으로 묶은 것은 해석이다. |
| 재활용품 가이드라인 | 게시본 파일이 2018년에 만들어졌다. 환경부 최신판이 있으면 교체한다. |
