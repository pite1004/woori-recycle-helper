| 단색 이미지 | 후보 0개 |
| 응답 시간 | 약 1.6~2.7초(품목 사전이 커졌지만 늘지 않음) |

직접 입력 해석:

| 확인한 조건 | 기대한 결과 | 발견·수정 | 다시 확인 결과 |
|---|---|---|---|
| 분명한 답 15개(예: "스테인리스예요", "알루미늄", "안에 솜이 들어 있어요", "손잡이가 빠져요", "사무실 의자예요") | 맞는 선택지, 확실 | 문제: 13개가 `null` 또는 불확실. 맞는 선택지를 고르고도 불확실로 답하기도 함("솜이 들어 있어요"→`cotton`, 불확실). 통과한 것은 "손잡이가 그냥 쭉 붙어 있어요", "소형가전 6개" 2개뿐. 앱은 선택지 버튼으로 다시 물어 잘못된 안내는 없었다. 원인 추정: 프롬프트가 "분명히 가리킬 때만"을 강조하고 판단 수준이 low. 수정: 일상어·묶인 선택지 기준과 예시를 넣고 판단 수준을 medium으로 올림 | 배포 후 확인 필요 |
