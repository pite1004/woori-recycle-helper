# 수용 기준 점검표

체크는 실제로 확인한 항목만 표시한다. 실제 전기포트 사진과 휴대전화 실기기 점검은 직접 진행해야 한다.

- [x] **1. 구를 고른 뒤 앱을 껐다 켜도 같은 구가 선택돼 있고 안내가 그 구 기준이다.**
  확인 방법: 미추홀구 선택 후 새로고침, 홈 지역 표시 유지 확인. 연수구로 바꾸면 같은 프라이팬 조건이 750원에서 870원으로 바뀜.
- [ ] **2. 전기포트 사진을 넣으면 '전기포트'를 포함한 후보 최대 3개가 표시된다.**
  확인 방법: 배포 URL과 실제 AI에서 코드로 그린 전기포트 이미지를 넣어 '전기포트' 후보 표시를 확인. **실제 전기포트 사진으로는 아직 확인하지 못함.** 2026-11-26부터 사진은 1장으로 시작하고 AI가 헷갈릴 때만 한 장 더 요청한다(`CHANGES.md` 참고).
- [x] **3. 후보를 바꾸거나 검색으로 고르면 질문과 안내가 바뀐 품목 기준으로 다시 그려진다.**
  확인 방법: 전기포트 답변 완료 후 헤어드라이어로 변경 시 첫 질문으로 초기화, 검색으로 프라이팬 선택 시 손잡이 질문 표시.
- [x] **4. 프라이팬을 고르면 손잡이 분리 여부·재질 질문이 선택지와 직접 입력 칸으로 표시된다.**
  확인 방법: 브라우저에서 두 질문의 버튼과 입력 칸 표시 확인.
- [x] **5. "나사가 있는데 잘 모르겠어요" → 미확정, 선택지 질문으로 넘어간다. 분명한 답변은 해석 결과 + [맞아요]를 눌러야 넘어간다.**
  확인 방법: 배포 URL과 실제 AI에서 확인. 불확실한 답변은 AI도 불확실로 반환했고 버튼 질문으로 이동. "손잡이가 그냥 쭉 붙어 있어요"는 해석 문구가 나온 뒤 [맞아요]를 눌러야 넘어가고 `ai-confirmed`로 저장됨.
- [x] **6. 분류·봉투·스티커·요일·시간·장소·비용·주의사항·출처·확인일이 한 화면에 표시된다.**
  확인 방법: 전기포트·의자 안내 화면에서 모든 항목 표시 확인.
- [x] **7. 그 구에 허용된 방법만 비용 낮은 순으로 표시되고 허용되지 않은 방법은 나오지 않는다.**
  확인 방법: 단위 테스트와 브라우저. 손잡이가 안 빠지는 프라이팬에 `allowed: false`인 고철 재활용이 나오지 않음. 분리되는 팬은 무료→750원 순.
- [x] **8. 저장 후 내 기록에서 품목명을 누르면 같은 지역·품목·확정 답변의 안내가 열린다.**
  확인 방법: 저장 전 화면과 다시 연 화면의 글자를 비교해 일치 확인.
- [ ] **9. 휴대전화 세로 화면에서 촬영부터 저장까지 가로 스크롤 없이 완료된다.**
  확인 방법: 360·375px 화면 크기 흉내에서 `scrollWidth`가 화면 폭과 같음을 확인. **실제 휴대전화와 카메라로는 아직 확인하지 못함.**
